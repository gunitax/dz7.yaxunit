# Переоценка товаров через сервис объектов — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в сервис объектов `POST /prices/reprice`, который переоценивает
выбранные товары на процент с даты, идемпотентен по дате и покрыт тестами YAxUnit,
написанными до кода.

**Architecture:** HTTP-обёртка (`СчетаМагазинаHTTP`) валидирует запрос и формирует
ответ; `СчетаМагазинаДанные` содержит чистый расчёт цены и переоценку с записью в
регистр; модуль HTTP-сервиса — только делегат. Тесты — в `СчетаМагазинаТесты`
(сначала юнит, затем интеграционные), запускаются через `1cv8c` без публикации.

**Tech Stack:** 1С:Предприятие 8.5.1.1529, БСП-демо 3.2.1.569, YAxUnit 25.12,
расширения `СчетаМагазина` и `СчетаМагазинаТесты`, jUnit-отчёты YAxUnit.

**Spec:** `docs/superpowers/specs/2026-11-11-reprice-service-design.md`

## Цикл проверки (выполнять после каждой правки)

Все команды — из PowerShell; кириллица в аргументах передаётся через
`Start-Process` (не через `.cmd`, чтобы не было проблем с кодировкой). Остановка
Apache — с повышением прав; в этой среде `ConsentPromptBehaviorAdmin = 0`, поэтому
UAC не показывает окно.

```powershell
$v8 = 'C:\Program Files\1cv8\8.5.1.1529\bin'
$base = 'D:\infobase\dz7.yaxunit'
$root = 'D:\AI.DZ7'
$logs = Join-Path $root 'build\tests'

function Run-Designer([string]$arguments) {
    $p = Start-Process -FilePath (Join-Path $v8 '1cv8.exe') -ArgumentList $arguments -Wait -PassThru
    if ($p.ExitCode -ne 0) { throw "DESIGNER exit $($p.ExitCode): $arguments" }
}

# Остановить публикацию: ibcmd и загрузка расширений требуют монопольного доступа.
$stop = Start-Process -FilePath 'powershell.exe' -Verb RunAs -Wait -PassThru -ArgumentList @(
    '-NoProfile','-ExecutionPolicy','Bypass','-Command','Stop-Service Apache2.4 -Force')
if ($stop.ExitCode -ne 0) { throw 'Не удалось остановить Apache2.4' }

Run-Designer "DESIGNER /F`"$base`" /N`"Администратор`" /DisableStartupDialogs /LoadConfigFromFiles `"$root\1c\extensions\СчетаМагазина`" -Extension СчетаМагазина /Out `"$logs\load-service.log`""
Run-Designer "DESIGNER /F`"$base`" /N`"Администратор`" /DisableStartupDialogs /UpdateDBCfg -Extension СчетаМагазина /Out `"$logs\update-service.log`""
Run-Designer "DESIGNER /F`"$base`" /N`"Администратор`" /DisableStartupDialogs /LoadConfigFromFiles `"$root\1c\extensions\СчетаМагазинаТесты`" -Extension СчетаМагазинаТесты /Out `"$logs\load-tests.log`""
Run-Designer "DESIGNER /F`"$base`" /N`"Администратор`" /DisableStartupDialogs /UpdateDBCfg -Extension СчетаМагазинаТесты /Out `"$logs\update-tests.log`""

# Снять безопасный режим и защиту (ibcmd доступен только при остановленном Apache).
& (Join-Path $v8 'ibcmd.exe') config extension update --db-path=$base --user=Администратор `
    --name=СчетаМагазина --safe-mode=no --unsafe-action-protection=no
& (Join-Path $v8 'ibcmd.exe') config extension update --db-path=$base --user=Администратор `
    --name=СчетаМагазинаТесты --safe-mode=no --unsafe-action-protection=no

# Запуск конфига: unit | integration | all
$config = 'unit'
Remove-Item (Join-Path $logs "$config.xml"),(Join-Path $logs "$config.exit"),(Join-Path $logs "$config.log") -Force -ErrorAction SilentlyContinue
$p = Start-Process -FilePath (Join-Path $v8 '1cv8c.exe') -PassThru -Wait -ArgumentList @(
    'ENTERPRISE', "/F`"$base`"", '/N"Администратор"', '/DisableStartupDialogs',
    "/C`"RunUnitTests=$root\tests\$config.json`"")
[xml]$report = Get-Content (Join-Path $logs "$config.xml") -Raw
$suite = $report.testsuites.testsuite
"config=$config exit=$((Get-Content (Join-Path $logs "$config.exit") -Raw).Trim()) tests=$((($suite | Measure-Object -Property tests -Sum).Sum)) failures=$((($suite | Measure-Object -Property failures -Sum).Sum)) errors=$((($suite | Measure-Object -Property errors -Sum).Sum))"
```
